Cloud Sync (Google Drive)

Automatically back up this browser's data to a file in your Google Drive, and pull it down on other devices you sign in on. Requires a free Google OAuth Client ID you create yourself — console.cloud.google.com/apis/credentials → Create Credentials → OAuth client ID → Web application → add this page's URL under "Authorized JavaScript origins" → enable the Drive API for the project.

Sync conflict

The cloud copy changed on another device since this browser last synced. Choose which version to keep — the other will be overwritten.
